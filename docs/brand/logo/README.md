# Abelkirar logo

A proposal. It is not used on the live site yet.

**The mark** is an abstract Kirar: a round bowl, long arms, a yoke with lifted
ends, and five strings meeting a bridge. The double diamond on the bowl echoes
the carved cross on the instrument. It shares its geometry with the motion
lab's five strings, so the logo can be "plucked" in animation.

**The wordmark** is ABEL KIRAR set in Fraunces (the site's heading typeface,
SIL Open Font License) with wide tracking. The letters are converted to
outlines, so no font needs to be installed.

## Rules

- Keep clear space around the logo at least the height of the letter A.
- Below 48 px tall, use `abelkirar-mark-small.svg`, which has three heavier
  strings and no diamond.
- Don't stretch, recolour outside the palette, add shadows, or put the logo
  on busy photography without a dark scrim.
- The site header currently reads "Abelkirar" (one word). This logo uses
  "ABEL KIRAR". Pick one spelling before rolling it out.
